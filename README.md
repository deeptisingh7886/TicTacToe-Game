# TicTacToe-Game

A simple and interactive Tic-Tac-Toe game built using Python. This project implements the classic 3×3 Tic-Tac-Toe game where two players take turns placing X and O until one player wins or the game ends in a draw.

Features
* Two-player gameplay
* 3×3 game board
* Detects winning combinations
* Detects draws
* Simple and beginner-friendly Python implementation
* Console-based interface

Technologies Used
Python

* Python functions
* Lists and loops
* Conditional statements
* User input
* Game logic
